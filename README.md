# スカイライン・テクノロジーズ 企業サイト

ソフトウェア開発会社「スカイライン・テクノロジーズ」のコーポレートサイトです。
「Build software like a city.（街のように、長く使われるソフトウェアを。）」をコンセプトに、都市のスカイラインをモチーフにしたデザインで構成しています。

## 概要

サイトは `index.html` 1ファイルで完結しています。CSS と JavaScript もこのファイルに含まれており、ビルドや依存パッケージのインストールは必要ありません（Web フォントのみ Google Fonts から読み込みます）。

## ブラウザで開く手順

### 方法 1: ファイルを直接開く

1. エクスプローラー（Mac の場合は Finder）でこのフォルダを開きます。
2. `index.html` をダブルクリックします。
   - 既定のブラウザ以外で開きたい場合は、右クリックして「プログラムから開く」でブラウザを選びます。
   - ブラウザのウィンドウに `index.html` をドラッグ＆ドロップしても開けます。

### 方法 2: コマンドから開く

このフォルダでターミナルを開き、OS に合わせて次のコマンドを実行します。

```powershell
# Windows (PowerShell)
start index.html
```

```sh
# macOS
open index.html

# Linux
xdg-open index.html
```

### 方法 3: ローカルサーバーで開く（任意）

Python がインストールされている場合は、簡易サーバーを立ち上げて表示することもできます。

```sh
python -m http.server 8000
```

ブラウザで <http://localhost:8000/> にアクセスします。終了するときはターミナルで `Ctrl + C` を押します。

> **補足:** Web フォントは Google Fonts から読み込むため、オフライン環境ではフォントが代替フォントで表示されます。
